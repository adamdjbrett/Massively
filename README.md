# Massively (Eleventy Port)

Eleventy port of the original Massively theme by TryGhost / HTML5 UP.

- Original theme: https://github.com/TryGhost/Massively
- Visual target: https://massively.ghost.io/

## Requirements

- Node.js 18+

## Install

```sh
npm install
```

## Local development

```sh
npm run start
```

## Production build

```sh
npm run build
```

Build output is generated in `_site/`.

## Notes

- Uses Eleventy `3.1.5`
- Uses a simple global data file: `_data/metadata.json`
- Markdown rendering uses `markdown-it` with `markdown-it-footnote`
